# ELSplit — модели для осмотра ножей

3D-модели ножей CS2 (руки + нож + анимации) и просмотрщик для окна магазина сервера ELSplit (CS:Source).
Магазин загружает их через jsDelivr: `https://cdn.jsdelivr.net/gh/<пользователь>/elsplit-models@main/`.

- `inspect.js` — просмотрщик (three.js)
- `models/knife_<id>.glb` — нож с руками и всеми анимациями (draw, lookat01/02/03, удары)
